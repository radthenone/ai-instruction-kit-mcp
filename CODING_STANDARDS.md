# Coding standards

Indeks źródeł standardów projektu — **kolejność oznacza ważność**. Ten plik
utrzymuje instruction-kit i odświeża go przy każdym reloadzie; reguły żyją
w źródłach, nie tutaj.

1. **`AGENTS.md`** — reguły pracy agentów w tym repo (najwyższy priorytet)
2. **`.ai/project.md`** — overlay projektu: nazewnictwo, konwencje API, biblioteka UI, ścieżki
3. **`BUGBOT.md`** — reguły review, w tym blok `project:rules`
4. **`docs/adr/`** — decyzje architektoniczne wiążące dla zmian
5. **`CONTEXT.md`** — słownik domeny — nazwy pojęć i ich znaczenie
6. **MCP `project-guides`** — `get_bundle` (Stack i Tiery) oraz `get_overlay` (overlay projektu)
