# Agent classification is a required contract, and the ponytail matcher lives in the untracked local settings

Every agent template carries a required `classification: procedure|code` in its frontmatter; a missing or unknown value fails the Bootstrap and the reload instead of falling back to `code`, because a silent default would let a procedure agent slip into the ponytail plugin's scope. The kit derives `PONYTAIL_SUBAGENT_MATCHER` from the `procedure` agents and writes it to `.claude/settings.local.json`, not the committed `settings.json`, because the agent list changes with each kit version and would churn a file shared by the team. `sync-local` and `prune-local` touch only the value in the kit's form and leave a hand-written value alone. `kit-ai doctor` reads `~/.claude/plugins/**` read-only to check the installed ponytail hooks; with no plugin and no manual matcher it stays silent, since the plugin is optional, and it warns only for an unsupported matcher, an invalid regex, or a matcher that still lets procedure agents through.
