# Backend — FastAPI (podpowiedź ścieżek)

Tier backend: `fastapi`. Domyślny katalog `backend/` — zapisz faktyczny w `## Ścieżki`
w `.ai/project.md` (klucz `backend:`).

```text
backend/
  src/app/
    main.py
    core/
    api/
    <feature>/
  migrations/
  tests/
  pyproject.toml
```

Pełny podział warstw: `stack:fastapi:structure`.
