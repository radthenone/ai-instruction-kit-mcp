# Frontend — React web + Expo mobile (split)

`--frontend react` + `--mobile expo`.

```text
frontend/
  web/                   # React DOM
    src/
      features/<feature>/
  mobile/                # Expo
    app/
    src/
      features/<feature>/
  packages/              # shared types, UI primitives
    <package>/
```

## Powiązane

- `arch:platforms`, `stack:expo-router:testing`
