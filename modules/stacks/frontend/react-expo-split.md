# Frontend — React web + Expo mobile (split)

Tier web: `react`, Tier mobile: `expo` — dwa katalogi, współdzielone typy.

```text
frontend/
  web/                   # React DOM
    src/
      features/<feature>/
  mobile/                # Expo
    app/
    src/
      features/<feature>/
  packages/              # shared types, UI primitives
    <package>/
```

## Powiązane

- `arch:platforms`, `stack:expo-router:testing`
