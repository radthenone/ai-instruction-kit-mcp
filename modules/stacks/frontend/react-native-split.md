# Frontend — React web + React Native (split)

Tier web: `react`, Tier mobile: `react-native` — dwa katalogi, współdzielone typy.

```text
frontend/
  web/
    src/
      features/<feature>/
  mobile/                # RN CLI / Expo bare — bez zakładania Expo Router
    src/
      features/<feature>/
  packages/
    <package>/
```

## Powiązane

- `arch:platforms`, `arch:testing`
