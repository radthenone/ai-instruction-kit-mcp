# Frontend — Expo unified (web + native)

`--frontend expo` + `--mobile expo` — jeden katalog `frontend/`.

```text
frontend/
  app/
  src/
    core/
    features/<feature>/
    ui/
      platform/          # .web / .native gdy trzeba
    api/generated/
  package.json
  app.json / app.config.ts
```

## Powiązane

- `arch:platforms`, `stack:expo-router:testing`, `arch:ui-ux-expo`
